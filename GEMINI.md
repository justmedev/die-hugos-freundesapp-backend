The purpose of this project is to create an app for my friend group. Every person can install this app on their phone (
the frontend is built using Flutter).

The backend follows Clean Architecture, Separation of Concerns, Single Source of Truth and Layered Architecture
patterns.

The backend is written in Kotlin using the most modern Kotlin and Ktor features. The backend is written scalably.

Ensure that any changes made are in the current style of the code and don't ignore the general architectural patterns.

Cashpools
---
Cashpools work similar to Splitwise, they split multiple bills or payments amongst a group of people, so each person
pays their fair share.
